# Arquitectura Inicial - SGI

## Estado del proyecto
El proyecto se encuentra en la etapa de planificación y diseño de un sistema de gestión de inventario. Las tareas se organizan mediante GitHub Projects.

## Objetivo
Desarrollar un sistema que permita organizar los productos y consultar las existencias, con acceso controlado para los usuarios.

## Problema que se busca resolver
El registro manual de productos y cantidades puede dificultar la actualización y consulta de las existencias. El sistema busca centralizar esta información.

## Funcionalidades previstas
- Analizar los requisitos del sistema.
- Diseñar la base de datos.
- Diseñar la interfaz de inicio de sesión.
- Implementar la autenticación de usuarios.
- Desarrollar la gestión de productos e inventario.
- Validar el funcionamiento de los módulos.
